# CampusPulse AI 🚀

CampusPulse AI is a digital campus command center for C.B. Bhandari Jain College.

## Current MVP
- Futuristic responsive dashboard
- Campus AI knowledge engine
- Interactive campus digital-twin map prototype
- Global search for rooms, people, events and departments
- Timetable
- Events
- Faculty / room / department directory
- Notices
- Mobile-friendly UI
- GitHub Pages compatible

## Run
Open `index.html` directly or use VS Code Live Server.

## Publish with GitHub Pages
Open **Settings → Pages → Build and deployment → Deploy from a branch → main → /(root) → Save**.

## Roadmap
1. Move sample data into JSON files.
2. Add verified college data.
3. Add real backend/database.
4. Add student, faculty and admin accounts.
5. Add QR event check-in and attendance.
6. Add indoor navigation.
7. Add secure AI API integration through a backend.
8. Connect an ESP32/Arduino campus robot to the digital twin.

**Security:** never commit passwords, private student records, API keys or secret tokens to this public repository.
